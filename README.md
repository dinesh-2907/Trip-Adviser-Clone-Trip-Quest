# 🌍 TripQuest - TripAdvisor Clone (HTML & CSS)

A responsive **TripAdvisor-inspired travel website UI** built using only **HTML and CSS**.  
This is my second frontend project focused on improving layout design, UI structuring, and responsiveness.

## ✨ Features

- 🧭 Modern travel website UI design
- 🏨 Hotel, destination, and travel section layout
- 🔍 Search bar UI (static design)
- 🖼️ Image-based hero section
- 📱 Responsive layout (mobile-friendly basic version)
- 🎨 Clean and professional styling using CSS

## 🛠️ Tech Stack

- HTML5
- CSS3
- Google Fonts
- Flexbox & Grid Layout

- Improving design consistency
